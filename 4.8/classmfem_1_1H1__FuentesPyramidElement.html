Detailed Description

Arbitrary order H1 basis functions defined on pyramid-shaped elements

This implementation is closely based on the finite elements described in section 9.1 of the paper "Orientation embedded high order shape functions for the exact sequence elements of all shapes" by Federico Fuentes, Brendan Keith, Leszek Demkowicz, and Sriram Nagaraj, see https://doi.org/10.1016/j.camwa.2015.04.027.

Evaluate the gradients of all shape functions of a scalar finite element in reference space at the given point ip.

Each row of the result DenseMatrix dshape contains the derivatives of one shape function. The size (dof x dim) of dshape must be set in advance.
